# AcikIstihbarat Haber Portali

Bu proje 3 ana bilesenden olusmaktadir:
1. **AcikIstihbarat.API**: .NET Core 8 Web API backend projesi.
2. **acik-istihbarat-public**: Next.js 14 tabanli SEO uyumlu, ziyaretciye acik frontend projesi.
3. **acik-istihbarat-admin**: React 18, Vite ve Tailwind CSS tabanli SPA admin paneli projesi.

## Projeyi Calistirmak
1. API projesi `AcikIstihbarat.API` altinda `dotnet run` ile calisir.
2. Public proje `acik-istihbarat-public` altinda `npm run dev` ile calisir.
3. Admin proje `acik-istihbarat-admin` altinda `npm run dev` ile calisir.
